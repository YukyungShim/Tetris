# 역할 부여
당신은 클래식 아케이드 게임 복원과 웹 프론트엔드 최적화에 특화된 시니어 풀스택 개발자입니다. 1988년 아타리(Tengen) 아케이드 버전 테트리스의 핵심 메커니즘을 모티브로 한 웹 테트리스 게임을 Next.js(React)로 개발하려고 합니다. 

# 기술 스택
- Frontend: Next.js (App Router 또는 Pages Router), React, HTML5 Canvas (또는 CSS Grid), Tailwind CSS
- Backend & DB: Supabase (PostgreSQL)
- Deployment: Vercel

# 핵심 게임 기획 및 요구사항

## 1. 게임 루프 및 렌더링 (아케이드 스테이지 모드)
- 10x20 그리드 시스템을 구현하세요. 렌더링 최적화를 위해 Canvas API 또는 최적화된 React 상태 관리를 사용하세요.
- **스테이지(Round) 기반 진행:** 무한 모드가 아닙니다. 각 라운드마다 목표로 하는 '남은 줄 수(Lines Left)'가 있으며, 이를 모두 클리어하면 다음 라운드로 넘어갑니다.
- **맵(미리 배치된 블록) 시스템:** 특정 라운드(예: 4라운드, 10라운드, 21라운드 등) 시작 시, 바닥에 미리 특정 패턴(예: 피라미드 모양, 무작위 빈칸이 있는 벽 등)의 쓰레기 블록이 깔린 상태로 시작하는 로직을 구현하세요.
- 라운드가 올라갈수록 블록의 낙하 속도(Gravity)가 빨라져야 합니다.

## 2. 테트리스 코어 로직
- 7가지 기본 테트로미노(I, J, L, O, S, T, Z) 배열과 각도별 회전(Rotation) 로직을 구현하세요. (월 킥/SRS 시스템 적용 시 가산점)
- 충돌 판정(좌우 벽, 바닥, 쌓인 블록)과 라인 클리어(Line Clear) 판정 알고리즘을 작성하세요.
- 점수 체계: Single, Double, Triple, Tetris 클리어 시 획득 점수가 다르며, 현재 '라운드'에 비례하여 점수에 배수가 적용되어야 합니다.

## 3. UI/UX 레이아웃
화면은 아케이드 캐비닛 느낌이 나도록 3구역으로 분할해 주세요.
- **좌측 패널:** 다음에 나올 블록(Next Block) 미리보기 영역
- **중앙 패널:** 실제 게임이 플레이되는 10x20 메인 보드와 중앙 오버레이 텍스트(현재 Round, Lines Left 안내 등)
- **우측 패널:** 'Stats' 영역. 현재 게임 중 어떤 모양의 테트로미노가 몇 번 스폰되었는지 보여주는 세로형 막대그래프(히스토그램) UI

## 4. Supabase 연동 글로벌 랭킹 시스템 (Vercel 배포용)
게임 오버 시 글로벌 랭킹에 기록을 등록하고 조회하는 로직을 통합하세요.
- **DB 스키마 가정:** `tetris_leaderboard` 테이블 (컬럼: `id` UUID, `name` VARCHAR, `score` INT, `round_reached` INT, `played_at` TIMESTAMPTZ)
- 클라이언트에서 직접 Supabase를 호출하거나 Next.js API 라우트를 경유하여 점수를 안전하게 INSERT 하는 함수 설계 (`@supabase/supabase-js` 활용)
- 메인 화면이나 게임 오버 화면에서 상위 10명의 랭킹을 렌더링하는 컴포넌트 추가
